# 《순환선》 M0 Asset Production Plan

기준일: 2026-11-09. 아트는 M0부터 개발과 병행한다. 아래 범위는 제작 순서이며 콘텐츠 최종 치수나 게임 수치를 확정하지 않는다.

| 단계 | 아트 산출물 | 선행 의존성 | 완료 검수 |
|---|---|---|---|
| M0 | 방향·기술 규격·모듈 카탈로그, 벽 기본/낡은형·바닥, 교체 fixture | GDD·평면도·개발 축/앵커 조사 | 샘플 bounds/TRS/재질, 구조 버전 차이 기록 |
| M1 | 환경 공용 atlas, texel density, 필터·mip 비교, 장벽/모서리/문틀 기초 | 구조 크기·문 폭 확정, 실측/단위 중심 계약 합의 | 실제 카메라 이동 shimmer, 90도 가림, 반복 질감 |
| M2 | 열차 3량 외형·내부, 기관실, 좌석·창고 | 차체 길이/좌석 수, 1인칭 이동·상호작용 거리 | 1~3호차 연결·패널/관제 테이블 식별, 안전한 생활감 |
| M3 | 역사 벽·바닥·기둥·문·승강장 kit, 관제 HUD용 아트, 승객 기본형 | 기획 구조 버전, Visual 분할 계약, HUD framework | 문 가독성·작은 인물 대비·geometry 불변 |
| M4 | 승객 걷기·회전·피격·쓰러짐·운반 | 연속 이동 속도, rig/animation event/socket 계약 | 좁은 문·회전·시신 운반, root motion의 경로 오염 없음 |

| M6 | 가속·브레이크·환승 장치, 창밖 풍경 | 실제 운행 알림·상호작용 상태 | 1인칭 조작 가독성, 역 접근 알림과 충돌 없음 |
| M7 | 착석 자세·초상화·대화 UI 아트 | 좌석 고정/파견 공석 상태, 대화 UI 계약 | 승객 직업·상태를 외형과 카드에서 구분 |
| M8 | 기본 몬스터 3종 제안: 쥐·들개·멧돼지, 기본 전투·준비 자세 | 공격 방향/시간·판정·스켈레톤 계약 | 약 4~6초 준비 자세 가독성, 빨간 공격 도형 없이 판독 |
| M9 | 장소 8종·복도 복합 장면 kit·식생 | 원정별 용도/점유 조합, 배치 envelope | 카운터 문법, 가변 정보 미공개, 통로 보존 |
| M10 | 나머지 5종(호랑이·달마상·석사자·보행작업기·인간형 괴수), 아이템·유물 | 종별 행동·아이템 카탈로그·부착 socket | 독립 실루엣, 위험 동작·회수 대상 구분 |

M8의 3종 선택은 아트 제작 제안이며 개발 마일스톤의 확정 순서가 다르면 그 순서를 따른다. M2~M10 전체 에셋을 M0에서 미리 완성했다고 보고하지 않는다.

## 우선순위

P0: GDD v1.1과 공통 v0.4 기준서의 K 밀폐/개방 구분 유지, 현재 실제 layout 자산값과 Visual Library 재질 덮어쓰기·비균일 스케일 계약 확인. 결합 방식이 확정되기 전 대량 모델링 금지.

P1: 실제 단일 앵커 통합 시험, 긴 벽과 남북 벽의 UV 문제 해소, 문 폭·바닥·모서리 최소 키트. M0 샘플을 production-ready 전체 역 키트로 취급하지 않는다.

P2: 열차 근접 시점과 역사 디오라마의 서로 다른 밀도·가림 검수. 핵심 인물·상호작용 대상보다 환경 디테일 대비가 강해지지 않도록 조정.

P3: 식생·소품 변형과 장소별 서사. 최종 지형이 아니라 가변 콘텐츠 상태에 적합한 묶음으로 제작.

## 총괄/개발 검수 요청

1. GDD v1.1 및 공통 기준서에 따라 PDF v0.4 구조를 유지한다. K3~K6의 밀폐부만 모델링하고 추가 공간 6개를 막지 않는다. 추가 공간의 방 안전 예외 적용 경계를 별도 결정한다. 아트는 구조 데이터를 변경하지 않았다.
2. 현재 기본 치수(1.5m 셀, 3.6m 벽, 0.22m 두께, 2.6m 문 높이, 0.25m 바닥)를 작업 기준으로 채택할지 확인한다. 포털별 문 폭과 원점은 실제 자산에서 받는다.
3. 단위 중심 호환 프리팹은 M0 교체 데모로 한정할지, 실측 모듈 반복 배치/방향별 매핑을 개발 측에서 마련할지 결정한다.
4. Collider/레이어/NavMesh/경로/문 좌표를 실제 맵의 Visual 교체 전후 비교한다. 현 샘플에서는 합성 fixture만 검사했다.
5. 4방향 디오라마 가림·시야·shadow 정책, 이동 중 필터/mip 비교, 플랫폼·천장·식생의 envelope를 합의한다.
6. 모델링 도구 및 FBX/GLB 왕복 검증 환경, 목표 하드웨어·해상도·FPS를 확정한다.

이 목록은 전달용 미결정 사항이다. 현재 요청 범위 안의 샘플 제작과 문서화는 승인 대기 없이 완료한다.
